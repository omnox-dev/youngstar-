# 🎨 Youngstar Frontend

React + Vite + Tailwind CSS web interface for **Youngstar Mitra Mandal**.

---

## 🚀 Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Vite Dev Server
```bash
npm run dev
```

The app will run at `http://localhost:3000` and automatically proxy `/api` requests to `http://localhost:5000`.

### 3. Build for Production
```bash
npm run build
```
The production bundle will be generated in `dist/`.
